20:T2b4a,<h2>문제 정리</h2>
<p><a href="https://www.acmicpc.net/problem/16931">백준 16931번: 겉넓이 구하기</a>는 격자의 각 칸에 단위 정육면체를 쌓았을 때, 완성된 도형의 겉넓이를 구하는 문제다. 입력으로 주어지는 수는 각 칸에 쌓인 정육면체의 개수, 즉 높이다.</p>
<p>격자의 행과 열은 각각 최대 100이고, 각 칸의 높이는 1 이상 100 이하이다. <strong>빈 칸이 없다는 조건</strong>을 기억해 두면 위·아래 면을 간단하게 계산할 수 있다.</p>
<p>배열의 모양에 따라 <code>1×1</code>, <code>1×M</code>, <code>N×1</code>, <code>N×M</code>으로 나누어 계산했다. 각 경우에서 위·아래 면과 가장자리의 옆면을 먼저 더하고, 이웃한 기둥 사이에 드러나는 면은 높이 차이로 구한다.</p>
<h2>위·아래 면은 칸마다 두 개</h2>
<p>한 칸에 정육면체가 몇 개 쌓여 있든, 맨 위의 윗면과 맨 아래의 아랫면은 각각 하나씩 드러난다. 중간에서 서로 맞닿는 면은 겉넓이에 포함하지 않는다.</p>
<p>모든 칸에 정육면체가 하나 이상 있으므로, 위·아래 면의 합은 다음과 같다.</p>
<pre><code class="language-text">위·아래 면의 넓이 = 2 × N × M
</code></pre>
<p>종이와 맞닿은 아랫면도 도형의 겉넓이에 포함한다. 위에서 보이는 면만 세면 안 된다.</p>
<h2>옆면은 가장자리와 높이 차이로 계산한다</h2>
<p>가장자리에 있는 기둥은 바깥쪽을 가리는 이웃이 없으므로 높이 전체가 드러난다. 따라서 각 행의 첫 칸과 마지막 칸, 각 열의 첫 칸과 마지막 칸의 높이를 더한다.</p>
<p>격자 내부에서는 이웃한 두 기둥 중 낮은 높이까지 서로 가리고, 높은 기둥의 나머지 부분만 드러난다.</p>

<p>어느 쪽이 더 높은지와 관계없이 차이만 필요하므로 절댓값을 사용한다.</p>
<pre><code class="language-text">이웃한 두 기둥 사이에 드러나는 넓이 = abs(한쪽 높이 - 다른 쪽 높이)
</code></pre>
<p>이 풀이에서는 각 행을 왼쪽에서 오른쪽으로, 각 열을 위에서 아래로 훑으며 <strong>이웃한 두 칸의 경계를 한 번씩만 확인한다.</strong> 따라서 절댓값을 더해도 같은 면을 중복해서 세지 않는다.</p>
<p>각 칸에서 상하좌우를 모두 확인하는 방식이라면 같은 경계를 양쪽에서 방문하므로 계산법이 달라진다. 여기서는 행과 열의 연속한 두 칸만 한 번씩 비교한다는 점이 핵심이다.</p>
<h2>배열의 모양에 따라 나누기</h2>
<h3>1×1 배열</h3>
<p>높이가 <code>h</code>인 기둥 하나이므로 위·아래 면은 2, 옆면은 네 방향에 각각 <code>h</code>만큼 드러난다.</p>
<pre><code class="language-text">겉넓이 = 2 + 4 × h
</code></pre>
<p>처음 코드의 <code>blocks[0][0] * 6</code>은 정육면체끼리 맞닿는 내부 면까지 포함한다. 높이가 2라면 두 정육면체가 맞닿은 면 두 개를 빼야 하므로 겉넓이는 12가 아니라 10이다. 아래 코드에서는 이 분기를 <code>2 + 4 * blocks[0][0]</code>으로 수정했다.</p>
<h3>1×M 배열</h3>
<p>한 행만 있으므로 <code>heights = blocks[0]</code>으로 높이를 가져온다.</p>
<ul>
<li>위·아래 면은 <code>2 * m</code>이다.</li>
<li>앞면과 뒷면은 모든 기둥의 높이가 그대로 드러나므로 <code>2 * sum(heights)</code>이다.</li>
<li>왼쪽과 오른쪽 끝면은 <code>heights[0] + heights[-1]</code>이다.</li>
<li>행 내부에서 드러나는 면은 이웃한 높이 차이 <code>abs(heights[i] - heights[i - 1])</code>를 더한다.</li>
</ul>
<h3>N×1 배열</h3>
<p>한 열만 있으므로 <code>heights = [row[0] for row in blocks]</code>로 높이를 모은다. 한 행일 때와 방향만 바뀐다.</p>
<ul>
<li>위·아래 면은 <code>2 * n</code>이다.</li>
<li>양옆 면은 모든 기둥의 높이가 그대로 드러나므로 <code>2 * sum(heights)</code>이다.</li>
<li>앞쪽과 뒤쪽 끝면은 <code>heights[0] + heights[-1]</code>이다.</li>
<li>열 내부에서 드러나는 면은 이웃한 높이 차이 <code>abs(heights[j] - heights[j - 1])</code>를 더한다.</li>
</ul>
<h3>N과 M이 모두 1보다 큰 배열</h3>
<p>위·아래 면의 넓이 <code>2 * n * m</code>으로 시작한다.</p>
<p>먼저 각 행에서 양 끝 높이 <code>blocks[i][0] + blocks[i][-1]</code>을 더해 왼쪽과 오른쪽 바깥 면을 센다. 이어서 같은 행에서 이웃한 두 칸의 높이 차이를 더한다.</p>
<p>다음으로 각 열에서 양 끝 높이 <code>blocks[0][j] + blocks[-1][j]</code>를 더해 앞쪽과 뒤쪽 바깥 면을 센다. 이어서 같은 열에서 이웃한 두 칸의 높이 차이를 더한다.</p>
<p>모서리 기둥의 높이가 행과 열에서 각각 더해지는 것은 서로 다른 방향의 옆면을 세기 때문이다.</p>

<h2>Python 풀이</h2>
<pre><code class="language-python">n, m = map(int, input().split())
blocks = [list(map(int, input().split())) for _ in range(n)]

# 1 * 1 배열일 때
if n == 1 and m == 1:
    print(2 + 4 * blocks[0][0])

# 1 * m 배열일 때
elif n == 1 and m != 1:
    heights = blocks[0]

    # 앞, 뒤, 위, 아래 면적의 합
    area = 2 * m + 2 * sum(heights)

    # 옆면의 넓이 합
    area += heights[0] + heights[-1]
    for i in range(1, m):
        area += abs(heights[i] - heights[i - 1])
    print(area)

# n * 1 배열일 때
elif n != 1 and m == 1:
    heights = [row[0] for row in blocks]

    # 양 옆, 위, 아래 면적의 합
    area = 2 * n + 2 * sum(heights)

    # 앞, 뒷면의 넓이 합
    area += heights[0] + heights[-1]
    for j in range(1, n):
        area += abs(heights[j] - heights[j - 1])
    print(area)

# n &gt; 1, m &gt; 1일 때
else:
    # 위, 아래 면의 합
    area = 2 * n * m

    # 앞, 뒤, 양 옆 면적의 합
    for i in range(n):
        area += blocks[i][0] + blocks[i][-1]  # 행의 양 끝
        for j in range(1, m):
            area += abs(blocks[i][j] - blocks[i][j - 1])

    for j in range(m):
        area += blocks[0][j] + blocks[-1][j]  # 열의 양 끝
        for i in range(1, n):
            area += abs(blocks[i][j] - blocks[i - 1][j])
    print(area)
</code></pre>
<h2>복잡도와 주의할 점</h2>
<p>각 행과 열을 한 번씩 순회하므로 시간 복잡도는 **O(NM)**이다. 한 행이나 한 열만 있는 경우도 각각 <strong>O(M)</strong>, **O(N)**으로 같은 범위에 포함된다.</p>
<p>입력 배열 <code>blocks</code>를 저장하므로 전체 공간 복잡도는 **O(NM)**이다. <code>N×1</code> 분기에서는 높이를 모은 리스트를 별도로 만들어 **O(N)**의 추가 공간을 사용한다. <code>1×M</code> 분기의 <code>heights = blocks[0]</code>은 기존 행을 참조하므로 리스트를 복사하지 않는다.</p>
<ul>
<li><strong>아랫면도 포함한다.</strong> 높이가 1인 정육면체 하나의 겉넓이는 6이다.</li>
<li><strong>1×1에서도 내부 면을 제외한다.</strong> 높이가 <code>h</code>인 기둥 하나의 겉넓이는 <code>6 * h</code>가 아니라 <code>2 + 4 * h</code>이다.</li>
<li><strong>가장자리 면을 따로 더한다.</strong> 행과 열의 양 끝에서는 높이 전체가 바깥으로 드러난다.</li>
<li><strong>인접한 경계는 한 번씩만 센다.</strong> 이 풀이에서는 행과 열에서 연속한 두 칸만 비교하므로 높이 차이에 절댓값을 사용한다.</li>
<li><strong>빈 칸이 없다는 조건을 사용했다.</strong> 높이 0이 허용되는 문제라면 위·아래 면도 실제로 기둥이 있는 칸만 세어야 한다.</li>
</ul>
<h2>정리</h2>
<p>위·아래 면은 칸 수로, 바깥쪽 옆면은 가장자리 높이로, 내부에서 드러나는 옆면은 인접한 높이 차이의 절댓값으로 계산했다. 배열의 모양에 따라 분기를 나누었지만, 모든 경우에 같은 원리로 면적을 더한다.</p>
<h2>더 개선한다면?</h2>
<p>처음에는 한 행이나 한 열만 있는 경우를 따로 처리했지만, 일반 격자를 계산하는 <code>else</code> 안의 코드를 보면 이 경우에도 그대로 사용할 수 있다. <strong>위·아래 면, 가장자리 면, 인접한 높이 차이</strong>를 더하는 원리가 배열의 크기와 관계없이 같기 때문이다.</p>
<p>열이 하나라면 <code>range(1, m)</code>은 비어 있으므로 행 내부의 높이 차이를 구하는 반복문이 실행되지 않는다. 이때 <code>blocks[i][0]</code>과 <code>blocks[i][-1]</code>은 같은 기둥을 가리키지만, 각각 왼쪽 면과 오른쪽 면을 세므로 둘 다 더하는 것이 맞다. 행이 하나인 경우도 같은 원리로 처리된다.</p>
<p><code>1×1</code>에서는 위·아래 면 2에 행의 양 끝에서 <code>2 * h</code>, 열의 양 끝에서 <code>2 * h</code>가 더해진다. 따라서 별도 분기 없이도 <code>2 + 4 * h</code>가 된다.</p>
<pre><code class="language-python">n, m = map(int, input().split())
blocks = [list(map(int, input().split())) for _ in range(n)]

# 위, 아래 면
area = 2 * n * m

# 왼쪽·오른쪽 가장자리와 각 행의 높이 차이
for i in range(n):
    area += blocks[i][0] + blocks[i][-1]
    for j in range(1, m):
        area += abs(blocks[i][j] - blocks[i][j - 1])

# 앞쪽·뒤쪽 가장자리와 각 열의 높이 차이
for j in range(m):
    area += blocks[0][j] + blocks[-1][j]
    for i in range(1, n):
        area += abs(blocks[i][j] - blocks[i - 1][j])

print(area)
</code></pre>
<p>시간 복잡도는 **O(NM)**으로 같다. 분기를 합치면 면적을 계산하는 코드가 한 곳에 모이므로 수정할 부분과 따로 확인할 예외 처리가 줄어든다. 한 열의 높이를 별도 리스트로 옮길 필요도 없어, 입력 배열을 제외한 추가 공간은 **O(1)**이다.</p>
